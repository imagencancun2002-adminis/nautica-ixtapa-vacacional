NÁUTICA IXTAPA VACACIONAL — sitio web bilingüe

CONTENIDO
- index.html: contenido de la página
- styles.css: diseño adaptable a celular y computadora
- script.js: selector de idioma y enlaces de WhatsApp
- images/: carpeta para agregar fotografías después

PARA PROBAR
1. Descomprime el ZIP.
2. Abre index.html en tu navegador.
3. Cambia entre ES y EN y prueba los botones de WhatsApp.

PARA PUBLICAR GRATIS EN GITHUB PAGES
1. Crea o inicia sesión en https://github.com/
2. Crea un repositorio público llamado nautica-ixtapa-vacacional
3. Sube los archivos index.html, styles.css, script.js y la carpeta images.
4. En el repositorio, entra a Settings > Pages.
5. En “Build and deployment”, selecciona “Deploy from a branch”.
6. Selecciona la rama main y la carpeta /(root), guarda.
7. GitHub mostrará la dirección pública cuando termine la publicación.
